The repository contains empirical datasets under:

data/experiments/

These datasets are evidence used for product and engineering decisions.

When a task references a dataset:
1. Read its README first.
2. Inspect the dataset structure.
3. Do not assume the sample is representative beyond what the README states.
4. Distinguish raw source data from derived/cleaned data.
5. Do not modify experimental datasets unless explicitly instructed.
6. Do not use experimental data as production application data unless explicitly
   promoted into the product dataset.
