# Git Pulse — Gemini Instructions

The canonical project instructions are in `AGENTS.md`.

Read it before modifying the project.

Then read the relevant files under `docs/`.

Git Pulse is:

> A live visualization of public GitHub activity happening around the world.

Preserve:

- 24-hour activity retention
- ActivityEvent abstraction
- profile-location-based geography
- location-owned coordinates
- repository-language semantics
- aggregate visualization
- PostgreSQL + Redis V1
- REST + WebSocket
- V1/V2/V3 architecture boundaries

Do not silently expand V1 scope.

Update project state and changelog after meaningful work.
